# Memeception

Pick a mood, browse memes from meme-api.com, and save the ones worth keeping. Saved memes and your theme stay in this browser's local storage.

This folder powers the live site. Vercel uses it as the project root, so a branch preview can be opened without changing production.

The experience branch adds a mood picker, a large meme viewer, surprise me, session back/next, optional auto-play, sharing, keyboard shortcuts, a saved preview, and a saved-memes drawer. The current blue, white, and navy theme stays in place in both light and dark mode.
